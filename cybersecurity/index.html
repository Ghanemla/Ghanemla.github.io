TeamprojektTeam project

Härdade en Debianbaserad server hela vägen som team: separata användarkonton med PAM-krav på lösenord, brandväggsregler i UFW, nyckelbaserad SSH och Fail2Ban mot brute force. Driftsatte Apache, PHP, MariaDB, phpMyAdmin och WordPress över HTTPS, och begränsade filöverföring till SFTP med dedikerade grupper, chroot-jails och minsta privilegium.Hardened a Debian-based server end to end as a team: separate user accounts with PAM password requirements, UFW firewall rules, key-based SSH and Fail2Ban against brute force. Deployed Apache, PHP, MariaDB, phpMyAdmin and WordPress over HTTPS, and restricted file transfer to SFTP with dedicated groups, chroot jails and least-privilege permissions.

Resultatet: en fungerande webbstack där varje tjänst kör med exakt den åtkomst den behöver — och inget mer.The result: a functioning full web stack where every service runs with exactly the access it needs — and nothing more.
